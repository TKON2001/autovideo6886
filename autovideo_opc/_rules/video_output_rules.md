# Video Output Rules

## Bat Buoc

- Video doc 9:16.
- 1080x1920.
- MP4 H.264.
- FPS 30.
- Audio AAC.
- Caption de doc tren mobile.
- Anh khong co text, watermark, logo.

## Khong Duoc Co

- Logo goc trai.
- Badge canh goc phai.
- Chu "Canh 1", "Scene 1" tren video.
- Watermark.
- UI element.
- Caption sat mep hoac bi cat.

## Caption

- Main caption ngan, toi da 12 tu.
- Nen o lower third.
- Nen co nen den ban trong suot hoac shadow.
- Safe margins:
  - top >= 180px.
  - bottom >= 240px.
  - left/right >= 90px.

## Render

- Neu render motion bang MoviePy qua cham, uu tien video on dinh truoc.
- File 0 byte la fail.
- File khong mo duoc la fail.
