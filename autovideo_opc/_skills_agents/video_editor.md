# Video Editor

## Nhiem Vu

Ghep anh, caption, voice, nhac nen va render thanh MP4 doc.

## Chuan Render

- 1080x1920.
- 30fps.
- MP4 H.264.
- AAC audio.
- `yuv420p` de tuong thich mobile.

## Layout

- Caption o lower third nhung khong qua thap.
- Khong logo goc trai.
- Khong badge canh goc phai.
- Khong watermark.
- Caption co nen toi ban trong suot hoac shadow.

## Mobile Safe Zone

- top margin toi thieu 180px.
- bottom margin toi thieu 240px.
- left/right margin toi thieu 90px.
- caption width khoang 860px.

## Loi Can Tranh

- File final 0 byte.
- Render qua nang vi animation frame-by-frame.
- Caption bi cat tren dien thoai.
- Video ngang 16:9.
