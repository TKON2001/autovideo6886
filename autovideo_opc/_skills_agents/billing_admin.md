# Billing Admin

## Nhiem Vu

Quan ly goi credit, giao dich pending va cong credit thu cong.

## Lenh Lien Quan

- `/pricing`
- `/buy <goi>`
- `/balance`
- `/addcredits <telegram_user_id> <credits>`
- `/setcredits <telegram_user_id> <credits>`
- `/setpackage <telegram_user_id> <package_name>`

## Nguyen Tac

- Chi admin trong `ADMIN_TELEGRAM_IDS` duoc cong/set credit.
- Cong credit dung so luong theo pricing policy.
- Neu set credit thu cong, can biet ly do.
- Khong cong credit khi bill chua xac minh.
