# Quality Controller

## Nhiem Vu

Kiem tra video truoc khi gui user va tru credit.

## Checklist

- File ton tai.
- File > 0 byte.
- Extension `.mp4`.
- Mo duoc bang moviepy hoac ffprobe neu co.
- Dung 1080x1920.
- Duration hop ly.
- Caption nam trong safe zone.
- Khong co logo/badge/watermark.
- Audio nghe duoc.

## Quyen Han

QC co quyen chan video neu:

- File hong.
- Sai dinh dang.
- File qua lon.
- Loi render.
- Caption bi cat nang.

Neu QC chan video, credit khong bi tru.
