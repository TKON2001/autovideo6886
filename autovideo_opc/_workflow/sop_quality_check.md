# SOP Quality Check

## Muc Tieu

Dam bao video du chat luong truoc khi gui va tru credit.

## Checklist

- File MP4 ton tai.
- File size > 0.
- File mo duoc.
- Dung resolution 1080x1920.
- FPS gan 30.
- Voice nghe duoc.
- Caption khong bi cat.
- Caption nam trong mobile safe zone.
- Khong logo goc trai.
- Khong badge "Canh" goc phai.
- Khong watermark.

## Khi QC Fail

1. Khong gui video cho user neu file hong.
2. Khong tru credit.
3. Thong bao user lich su:
   "Video chua dat kiem tra chat luong. Credit chua bi tru. Vui long thu lai."
4. Ghi log loi cho admin.

## Khi QC Pass

- Gui video.
- Sau khi gui thanh cong moi tru credit.
