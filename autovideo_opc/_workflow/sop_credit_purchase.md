# SOP Credit Purchase

## Muc Tieu

Quan ly viec user mua credit thu cong qua chuyen khoan va admin cong credit.

## Quy Trinh

1. User bam Bang Gia hoac dung `/pricing`.
2. User chon goi bang `/buy starter`, `/buy creator`, `/buy pro`, `/buy agency`.
3. Bot tao purchase pending.
4. Bot hien thong tin chuyen khoan.
5. User gui bill cho admin.
6. Admin doi chieu so tien va noi dung chuyen khoan.
7. Admin dung `/addcredits <telegram_user_id> <credits>`.
8. Admin co the dung `/setpackage <telegram_user_id> <package_name>`.

## Kiem Tra

- So tien phai khop goi.
- Telegram ID phai dung user.
- Credit cong phai dung pricing policy.
- Khong cong credit neu bill khong ro.

## Loi Thuong Gap

- User chuyen sai noi dung.
- User gui bill nham.
- Admin cong nham ID.
- User chua bam `/start` nen chua co profile.

Neu user chua ton tai, admin co the yeu cau user bam `/start` truoc.
